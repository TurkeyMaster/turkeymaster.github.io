I'm **Zachary Holmes**, better known online as **Big-Z** or **TurkeyMaster**. I'm a games journalist, C++ developer, and reverse engineer. I run a gaming news site by day and take apart Windows software by night.

## What I write about here

*Big-Z Breaks Things* is where I publish security research on the software gamers trust most: game launchers, auto-updaters, add-on and mod systems, and the local services and APIs behind them. The question I start with is simple: **if the server lied, would the app notice?**

Everything I publish is based on software I own, tested on my own machines. Findings go to the developer first.

## Research and disclosure

If you maintain software I've written about and want to talk about a finding, open an issue on the project or reach me through [GitHub](https://github.com/TurkeyMaster). I'm happy to hold a post until a fix ships.
